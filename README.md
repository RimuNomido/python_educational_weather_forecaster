# 🌤 Погодный терминал

Консольный инструмент для получения актуальной погоды по названию города через **Yandex Weather GraphQL API**.  
Проект написан на Python и идеально подходит для знакомства с API, парсингом JSON и работой с командной строкой.

---

## 🚀 Возможности

- Определение координат города через **Nominatim** (OpenStreetMap)  
- Запрос к **Yandex Weather API** с получением:
  - температуры (в °C и °F)
  - скорости и направления ветра
  - влажности, облачности
  - типа и интенсивности осадков
  - атмосферного давления
- Красивый вывод в консоль с русским интерфейсом  
- Выбор города через аргумент командной строки (`--city`)  
- Автоматическое склонение названия города для грамотного отображения

---

## ⚙️ Установка

```bash
git clone https://github.com/your-username/python_educational_weather_forecaster.git
cd python_educational_weather_forecaster
python -m venv venv
source venv/bin/activate   # или venv\Scripts\activate для Windows
pip install -r requirements.txt
```

Если `requirements.txt` отсутствует, установите вручную:

```bash
pip install geopy requests python-dotenv typer pymorphy3
```

---

## 🔑 Ключ доступа

Создайте файл `.env` в корне проекта и укажите ваш API-ключ:

```env
access_key=ваш_ключ_яндекс_погоды
```

Получить ключ можно в [Яндекс.Облаке](https://cloud.yandex.ru/) (сервис «Погода»).

---

## 🖥 Использование

Запустите программу:

```bash
python main.py
```

По умолчанию показывает погоду в **Сочи**. Для другого города:

```bash
python main.py --city "Москва"
python main.py -c "Санкт-Петербург"
```

**Пример вывода:**

```
**************Погода в Москве***************
Облачность: overcast
Влажность: 78%
Тип осадков: rain
Интенсивность осадков: light
Атмосферное давление: 745 мм рт. ст.
Температура: 18 °C
Температура по Фаренгейту: 64 °F
Скорость ветра: 3.2 м/с
Направление ветра: NW
***************************************************
```

## 🛠 Технологии

- Python 3.8+
- `requests` – HTTP-запросы
- `geopy` – геокодинг
- `pymorphy3` – склонение городов
- `typer` – интерфейс командной строки
- `python-dotenv` – управление переменными окружения
